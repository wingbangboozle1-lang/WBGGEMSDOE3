## Pass 2 — review, defects found and fixed

1. **Site generator imported the wrong source of truth.** `build_executive.py` read `docs/data/run_card.json`
   (the *mirror*) instead of `evidence/gemsdoe_run_card.json` (the writer's output) → `KeyError: 'download'`.
   Fixed: the run card is the input, the mirror is an output.
2. **Template-literal slip.** Nested f-string quotes in the uniqueness table raised `SyntaxError`; the class
   was hoisted to a plain variable. Caught by `python -c "import ast"` before any page was written.
3. **`action` referenced before assignment** after the hypothesis block was regenerated from the layer
   ranking → `NameError` at build time. Fixed by defining the download banner before the science page.
4. **Non-deterministic zip.** `zipfile` stamped the current time, so `gd_finalize.py` produced a different
   zip hash on every run. Fixed with a fixed `ZipInfo.date_time`; two consecutive runs now produce the same
   TIF SHA-256 (`610acf58…`) and zip SHA-256 (`c5befcde…`).
5. **Site checker asserted the old negative verdict.** `check_site.py`/`test_site.py` required the string
   "No competition file is cleared." Fixed: the checker now reads the verdict from the run card, requires the
   `gemsdoe-decision` meta tag on every page, resolves every local link, and re-hashes the published TIF.
6. **Legacy rasters were moved out of `docs/downloads/` by the builder**, deleting three tracked files and
   duplicating 650 KB. Reverted; instead a `LEGACY-DO-NOT-SUBMIT.txt` notice is written and the downloads
   index names the legacy files without linking them. A test enforces "no `<a href>` to a legacy raster".
7. **Stale pages still advertised a stop.** `docs/submission.html` and `docs/downloads/index.html` were
   generated by the retired builder. `submission.html` is now a redirect to the executive summary;
   `downloads/index.html` lists exactly one cleared file plus the vetoed set.
8. **Two numbers on the science page were hand-typed** from earlier ad-hoc runs. Replaced with values read
   from `evidence/layer_ranking.json` (86 channels, top-20k two-polarity support, proxy h). The superseded
   figures (0.180 / 0.065 / 0.013) do not appear anywhere now.
9. **LiDAR band names were read from the wrong sidecar** (`…_u8.json` does not exist; the metadata is
   `lidar_scarp_features.json`), so 12 channels were ranked under invented names. Fixed; `strike` and `valid`
   are now excluded explicitly because a two-polarity ranking of a circular quantity is meaningless.
10. **Sensitivity table rendered the sign backwards** ("0.371 at |G|=8430" when 0.513 is at 8,430). Fixed to
    compute min/max from the dict instead of hard-coding endpoints.
11. **Road-confound figure overstated its coverage.** 4.4% vs 7.3% is computed inside the 42% of the footprint
    covered by TIGER roads; the page now says so.
