Why H33-B2 is the historic high in this group

Mechanistic interpretation: the owner audit describes the H33-B2 file as progressively thinning a shared H19-5 lineament/dot field and removing catalogue-proximal predictions. Under the specified Tversky-style objective and triangular kernel, tightly clustered predictions can contribute overlapping credit, while each prediction still carries false-positive cost. Removing low-marginal-credit dots can therefore improve the score ratio.

What is directly supported: the H33 artifact audit names a B2 pruning rule and lists a valid-looking all-finite file on an owner-mirrored grid. This checkout independently verified the stored file's SHA-256 matches that audit, but did not read its geospatial metadata because rasterio and the competition sample grid are absent.

What is not supported: the score does not prove that H33 discovered more new geology, that the pruning causal effect will generalize, or that a new candidate will exceed it. All nine bests share one family or closely nested masks, so they are not nine independent scientific replications.

Global leaderboard values are inconsistent

The request states both 0.3195 and 0.4413 as the current high. A GEMSDOE32 owner-maintained snapshot records 0.4437 at 2026-10-26T21:20:39Z. The leaderboard host was not fetched directly in this sandbox; these values are not independently confirmed here. Do not use them as a target calibration until the official page and a timestamped capture agree.
