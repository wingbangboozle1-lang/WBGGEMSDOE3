## Mandatory research and release protocol

1. **One explicit method lane.** Do not infer or choose a method when the task has not assigned a lane. Compare the pre-placement continuous surface and final dots with every registry raster. If `|Spearman| > 0.90` or more than 70% of candidate dots lie within 3 px of any registry raster, record a duplicate and stop. Do not exempt dense calibration/null controls.
2. **Reuse the shared tools.** Use the cached feature stack and shared `evaluate_holdout.py` and `submission_writer.py`; do not make a private fork. Do not use sample-submission values or historical prediction masks as geological features.
3. **Buffered hide-and-recover holdout.** Hide whole fault segments with a buffer; rebuild all catalogue-derived features using visible faults only; mask visible fault pixels exactly; then score pooled DTI (`alpha=0.2`, `beta=0.8`, 300 m triangular kernel). Random-pixel splits are not acceptable.
4. **Leakage canary.** Run each feature alone on the same holdout. AUC above 0.90 is leakage until disproven.
5. **Evidence labels.** Label a measured result `HOLDOUT-DTI` with evaluator version, withheld-positive count, and 95% CI, or `ORGANIZER-CONFIRMED` only with the matching submission receipt. Projections are never scores. Historic site values without a byte-linked receipt remain user/owner-reported.
6. **Fail closed.** Keep format, novelty, holdout, organizer confirmation, and weekly-slot authorization distinct. A valid GeoTIFF is not automatically unique, useful, accepted by the portal, or safe to submit. Never silently clip/fill invalid predictions.
