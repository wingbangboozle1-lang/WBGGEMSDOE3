Submission mechanics

When a file is cleared, it is uploaded unchanged with the run card's unique submission_name and a note of at most 140 characters. The portal error "Predicted values must be in range [0, 1]" comes from NaN, nodata sentinels or values above 1 inside the footprint. This repository's writer emits finite 0/1 float32 values only.
