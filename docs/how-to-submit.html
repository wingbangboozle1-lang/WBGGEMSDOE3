How to submit — exactly

One file, one note, no manual geology. Everything below is checked by code; the only human step is pressing upload on the DrivenData form.

Step 2 · Fill in the form

  1. Submission page: competition leaderboard / “New submission”.
  2. File to submit — choose the downloaded .tif. Do not zip it; a single-band GeoTIFF is accepted directly.
  3. Note (≤140 characters, 120 used): TDE-30k: truth-posterior from score tomography x lidar/gravity/magnetic edge concordance; all dots >=200 m off catalogue
  4. Submit. The portal should accept the file: values are finite and inside [0, 1] for every cell (that was the cause of the “Predicted values must be in range [0, 1]” rejection seen earlier).

Reproduce the file from scratch

bash scripts/restore_shared_data.sh          # pinned shared template
bash scripts/fetch_mirrors.sh                # 26 SHA-256-pinned data mirrors
.venv/bin/python scripts/fetch_ledger_rasters.py --jobs 6   # 118 scored probes, sha-verified
.venv/bin/python scripts/build_probe_set.py  # 400 m score operators + official feature blocks
.venv/bin/python scripts/invert_ledger.py --folds 3 --iters 100 --n-outer 3
.venv/bin/python scripts/emit_candidate.py --name wbggems3-tde --quota 30000 \
    --alpha-rho 12 --beta-S 0.3 --min-sep 1.5

Requires Python 3.11+, ~2 GB RAM, network access to github.com and PyPI. Every mirror is hash-checked; a mismatch aborts the run.
