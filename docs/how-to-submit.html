Submission guide

How to make a submission into the DOE GEMS Prize

This page explains exactly how to submit a GeoTIFF to the competition. Read the full procedure before uploading. At present the repository-wide gate is DO-NOT-SUBMIT: no file here is cleared for upload.

READ BEFORE UPLOADING

Prerequisites

  • Format: single-band GeoTIFF (.tif), or a .zip containing exactly one GeoTIFF.
  • Grid: must match the submission format's CRS, shape, and geotransform: EPSG:32611, 3730×3292, 100 m resolution, origin (243350, 4508550).
  • Values: float32, all finite predictions inside the footprint must be in [0,1]. Outside the footprint: NaN (nodata).
  • Name: give the file a unique name.
  • Note: add a short comment (≤140 characters) to tell submissions apart, e.g. "clustering with k=25".

Step-by-step

  1. Verify the gate. Check the executive summary decision banner. If it says DO NOT SUBMIT, do not upload. The release gate must show a compliant HOLDOUT-DTI, passing uniqueness, and selector approval for the exact SHA-256.
  2. Download the TIFF. From the executive summary, download the exact GeoTIFF and verify its SHA-256 against the published manifest.
  3. Format-check locally. Confirm single band, float32, EPSG:32611, 3730×3292, exact transform, NaN outside footprint, all in-footprint values in [0,1]. A past portal error ("Predicted values must be in range [0, 1]") was caused by out-of-range values — this check prevents it.
  4. Log in to DrivenData. Go to the competition page and navigate to New submission.
  5. Upload the file. Select the single GeoTIFF or ZIP. The portal validates CRS, shape, and geotransform automatically.
  6. Add a note. Enter a unique note (≤140 characters) so you can tell submissions apart later (e.g. clustering with k=25).
  7. Check the weekly cap. The rules allow three submissions per week per entity. Confirm you have quota before uploading.
  8. Submit and save the receipt. Keep the organizer submission receipt together with the file's SHA-256. Only an organizer receipt is an ORGANIZER-CONFIRMED score.
