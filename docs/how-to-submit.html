How to submit

OK to submit

1. Download

Clearance lives on one page only. The sentence that says whether you may spend a slot is on the landing page; this page never restates it, so there is exactly one place to check. It is derived from evidence/release/candidate_run_card.json — promote with 11/11 format checks and 4/4 uniqueness checks passing.

2. Create the submission

  1. Open the submission page and choose New submission.
  2. File to submit: the downloaded .tif. Do not zip it and do not re-save it in image software — a round-trip can change the dtype or the geotransform.
  3. Note (optional, ≤ 140 characters) — paste this exactly:
    WB-GEMS-DOE-3 CIFS CAT | 139957 dots, catalogue-free multi-physics concordance, >300 m collar | multi-physics structural detector, catalogue
  4. Submit. A weekly slot is consumed by the attempt, so check step 3 first.

If the portal still says "Predicted values must be in range [0, 1]"

That message means at least one finite cell outside [0, 1], or a NaN where the reader expects a number. This file has neither: every finite cell is exactly 0.0 or 1.0 and the only non-finite cells are the NaN cells outside the footprint, which the official format requires. To prove it for any file yourself:

python scripts/release_audit.py --file <path-to-your-tif>

The script re-runs all 11 format checks and all 4 uniqueness checks and prints the exact failing check name.

What the file is

  • 139,957 cells at probability 1.0, 5,167,373 cells at 0.0 inside the study footprint, NaN outside.
  • Every 1.0 cell is at least 3.16 px (300 m) from the nearest mapped fault and none is on the mask.
  • Minimum separation between dots: 2 px, so the budget buys distinct structure rather than blobs.
  • The model, features, holdout and controls are on the research page; the numbers behind every claim are in evidence/release/.

Rules to keep in mind

  • Three submissions per week per entity and one final submission across both prize rounds (official rules). A slot is a scarce resource — this site tells you exactly one file to spend it on.
  • The public score is not the final score: the private leaderboard and the final re-evaluation are re-scored on a different label set; the final re-evaluation covers the entire GeoDAWN area and also masks the existing faults.
  • Disclose generative-AI assistance in the written narrative if you use this work in a prize submission, as the rules require.
