How to make a submission (exact steps)

Everything is prepared; submitting takes about two minutes on the DrivenData form.

Step 1 — Download the file

wbggems3-khd-tomo-20261028-bd69b5b3-zeros.tif  ZIP version (also accepted)

This is a single-band GeoTIFF. sha256: 787f83e11d9e3c28b742e8fc3b02af97553a872e3b88bf9b74abb2b2d5866aaa. If your browser saves it with a different name, rename it back to wbggems3-khd-tomo-20261028-bd69b5b3-zeros.tif (any .tif name works; the name only matters for your own bookkeeping).

Step 2 — Open the submission page

https://www.drivendata.org/competitions/306/competition-doe-gems/submissions/ (login required). Click New submission.

Step 3 — Choose the file

Under File to submit, choose the .tif (or the .zip). The form accepts “a single-band GeoTIFF (.tif) file, or a .zip file containing a single GeoTIFF”.

About the earlier error “Predicted values must be in range [0, 1]”: that is the portal's range check. Files written with NaN outside the footprint (the older -nan variants) fail it because NaN is not in [0, 1]. The file on this page is the all-finite -zeros encoding: every one of the 12,279,160 values is in [0, 1] — verified byte-by-byte before publication (see evidence). This is the same encoding as the 0.2778 GEMSDOE32 B2 file.

Step 4 — Fill the note

In Note (optional), paste this comment (so you can tell submissions apart later):

KHD ledger-tomographic rho x tri-domain concordance; 2px catalogue trim; comparator caps 0.64; zeros-outside

The suggested submission display name is wbggems3-khd-tomo-20261028-bd69b5b3-zeros (140-char limit respected: 41 chars).

Step 5 — Submit and record the receipt

Press Create submission. DrivenData shows a score receipt. Copy the exact score into your records with the file's sha256 (787f83e11d9e3c28…). Every number on this site labelled ESTIMATE or OWNER-REPORTED is not a score — only the receipt is.

Competition rules: ≤ 3 submissions per week, one final choice across rounds, generative-AI disclosure, reproducible solution assets (rules PDF). Promotion to a weekly slot is the selector's decision — the score band for this file (0.23–0.31) straddles the current family best (0.2778), so treat the slot as a measured bet, not a certainty.
