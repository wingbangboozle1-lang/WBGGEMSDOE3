What the estimate means — and what it does not

The metric is a distance-weighted Tversky index with α = 0.2, β = 0.8 and a 300 m triangular kernel. For a binary prediction, FN = |G| − TP, so DTI = T / (0.2·(T+F) + 0.8·M) = T / (0.2N + 0.8M), where N is the number of dots, T the truth cells they reach, and M the (hidden) number of truth cells. We solved M and T from a pair of real submissions whose dots differ by an exact subset relation: M ≈ 15,200 hidden truth cells, and the 0.2778 champion reaches T ≈ 5,470 of them.

This submission beats 0.2778 if its dots reach truth at a rate above 0.22 credit per dot; the measured sibling rate is 0.124–0.145. Our ordering statistic claims 1.70× the champion's rate, so the model estimate is 0.47. That uplift is a model claim, not a measurement — which is why the honest band is 0.18 (no better than siblings) to 0.58 (posterior exactly right).
