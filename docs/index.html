Scientific Hypothesis (PhD-Level)

LLI-UNIQUE / HYDROTHERMAL-CONDUIT-EDGE-DETECTION

Layers involved: 1m DEM curvature (simulated proxy), multi-scale curvature gradient (300m / 600m / 1200m triangular kernels), thermal-gradient proxy (simulated alteration-zone intensity).

Physical signature targeted: Multi-scale curvature anomaly edges + thermal-gradient corridors that represent hydrothermal alteration zones lacking surface fault expression in the USGS Quaternary Fault Dataset or INGENIOUS catalogue.

Why it catches missing faults: Standard registry replication (H19-5 dotted-ridge family) replicates known surface lineaments but misses subsurface alteration zones and hidden fault tips that terminate before surfacing. This approach targets curvature discontinuity at alteration-zone boundaries rather than line replication.

How it differs from repo implementations: Repo uses dotted-ridge replication (GEMSDOE25/29), emission top-k (GEMSDOE30), Poisson lattice (GEMSDOE32), or ridge-scatter (GEMSDOE36). This uses curvature-gradient peak detection with suppression near visible catalogue faults and no point-pattern replication.

Non-fault mimic: Erosional scarps, fluvial terraces, glacial moraines. Filtered by stress-direction alignment, thermal-proxy correlation, and aspect-ratio exclusion.
