What the estimate means — and what it does not

The metric is a distance-weighted Tversky index with α = 0.2, β = 0.8 and a 300 m triangular kernel. For a binary prediction, FN = \|G\| − TP, so DTI = T / (0.2·(T+F) + 0.8·M) = T / (0.2N + 0.8M), where N is the number of dots, T the truth cells they reach, and M the (hidden) number of truth cells.

Our submission raises the credit rate two ways: (i) it places dots entirely off the catalogue network (0.0000 overlap with any focus file), and (ii) it ranks ground by a blind-fault suitability map (distance from explored territory + basin structure) and spends a bounded budget of 15,000 dots at 5 px minimum separation.

Risk, stated plainly: no holdout truth labels are available in this sandbox (DrivenData training data requires login). The estimate is a model claim, not a measurement. Spend one slot, read the receipt, then act on it.
