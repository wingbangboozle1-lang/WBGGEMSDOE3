02 / Why it works

What changed scientifically

The 0.2778 reference is a pruning, not a new model

Independent byte-level measurement: the GEMSDOE32 H33-B2 file has 37,654 positive pixels and is an exact subset of the H27-4 base (40,199). The 2,545 removed pixels sit within 2 px of mapped faults — cells the organizer excludes from evaluation. Under α=0.2 / β=0.8 with a max kernel, removing predictions that cannot earn credit reduces FP without reducing TP. That is a metric-optimal pruning of one static ridge network. Full derivation →

SGCE: coverage, not a fixed network

Twenty official/mirrored geophysical, topographic, strain, radiometric and scarp fields are combined with fold-local visible-fault geometry (PCA strike continuation, relay ramps, 1.5 km annulus), gated by geodetic strain. Binary dots are then placed by the exact DTI marginal gain instead of a fixed dot quota. No prior submission raster enters the density. Result: 0.1675 vs 0.0992 HOLDOUT-DTI on identical folds.

03 / Flags for review

Read before uploading

  • Literal registry rule. A registered 17GEMSDOE continuous probability raster is positive on all 5,167,373 footprint cells, so the literal “70% of dots within 3 px of one registry raster's dots” test is 100% for any nonempty candidate. We preregistered a content-aware reading (discrete sparse emission masks for the overlap test; rank correlation and excess-over-random-null for continuous/lattice controls) and report both. This is a documented interpretation requiring your ratification, not a silent threshold change.
  • No receipt. Owner-reported historical figures and our projection are not organizer-confirmed scores. Holdout DTI is a proxy on withheld catalogue segments, not the expert-labelled new-fault test set.
  • Holdout vs projection disagreement (important). The released file wins the matched holdout by +0.0683 but the ledger-calibrated projection is only 0.0669. Every high-scoring raster in the 117-file ledger overlaps the same H19-5 network, so the projection has no example of a high-scoring unique construction and extrapolates poorly. A dot-cap scan (30k–80k dots) did not rescue the projection. Treat the holdout as the protocol's promotion gate and the projection as an unreliable lower-band guess; only an organizer receipt can settle it. Inspect the projection evidence ↓
  • Mirror provenance. Competition rasters were restored from hash-pinned public GitHub mirrors, not an authenticated DrivenData download; hashes prove consistency, not official origin.
  • Outside-footprint convention. The official text says null/NaN outside bounds while the mirrored sample is NaN outside an irregular finite footprint. Both encodings of the same prediction are supplied and validated. Portal acceptance is unverified.
