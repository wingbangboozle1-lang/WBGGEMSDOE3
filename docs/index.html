Why this release is not a copy

  • The dots come from 14 feature planes computed from the official 19-band stack, none of which uses the fault catalogue; the catalogue is used only as supervised labels under spatial blocking and as the official masking geometry.
  • The model is a gradient-boosted classifier on 100,000 training cells, refitted here; 40,000 positive and 60,000 negative cells.
  • Uniqueness, defined so that it can actually fail. The literal 70 %/3 px rule cannot distinguish anything: measured across the nine focus files, every pair overlaps at 0.976-1.000, because one file with 60k dots covers the region at 3 px. This release therefore reports three numbers that can fail: a byte-duplicate check, the maximum 3 px overlap with any single focus file, and the absolute Spearman rank correlation. The overlap result is what matters: only 29.7% of this release's dots lie within 3 px of the nearest focus-file dot, i.e. the emission is mostly finding different structure.
