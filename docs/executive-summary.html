Submission guide

How to actually submit the SMSR file

  1. Download smsr-seisgeod-missingshear-detached-20261028T000000Z.tif and optionally verify sha256 a80e8a866c7421c1344d299874e3444e7282c0d6b8488054d999b16ca3db662d.
  2. Sign in to DrivenData's submission page and check your current weekly quota there — a selector decision to actually spend a slot is a separate human step from this project's own validation.
  3. In the "File to submit" field choose the downloaded .tif; in the "Note" field enter a short note such as 4-quadrant OOF HGB on geod_2ndinv structure-tensor ridge + seismicity vs shipped G1-G5 (under the 140-character limit).
  4. Submit, then save the receipt with the exact file hash. Only an actual receipt establishes an ORGANIZER-CONFIRMED result.
