Reading the table

  • Owner-reported — the score posted on the owner's site for that file. Evidence class: OWNER-REPORTED receipt; not independently authenticated (no DrivenData receipt was obtained in this sandbox).
  • Model estimate — leave-one-out projection from the ledger-tomography instrument trained on 112 unique owner-scored rasters (LOO MAE 0.0251, Spearman 0.907). It is an ESTIMATE. It carries a systematic +0.025 optimistic bias on this family.
  • Directed 3-px overlap — the parallel-run protocol's duplicate test: the fraction of our candidate's dots that fall within 3 px of that file's dots. Above 0.70 would mean we drifted into that lane. Ours is ≤ 0.59 against every focus file and ≤ 0.64 against every registered sparse mask.
  • Unique: YES — our candidate is NOT a copy or near-copy of any listed submission. Byte-level: its sha256 (787f83e11d9e3c28…) matches no registered raster; its dot mask is not identical to any of the 148 compared masks.
  • Estimates and owner reports are never scores. Every figure below carries an evidence class label; none is an organizer-confirmed score. Organizer-confirmed scores exist only as receipts on your own DrivenData submission page.
  • Submission comment limit: the DrivenData note field is optional and should stay ≤ 140 characters (ours: 108). The portal range check rejects files whose values leave [0, 1] — e.g. “Predicted values must be in range [0, 1]” for NaN-outside encodings; the released file is all-finite binary 0/1 with zeros outside the footprint.
