Best first test		 Signed magnetic–gravity phase pairing
Competition template bands reported as RTP / TMI and isostatic gravity, including their horizontal/vertical derivatives. Use the exact template feature names only after checking its band manifest.		 At more than one spatial scale, compare the sign and orientation of magnetic and gravity curvature/zero-crossing ridges; retain line segments only where the independent potential fields show compatible phase and strike. A buried basement fault can offset susceptibility and density contrasts even where alluvium removes the surface scarp. Requiring cross-field agreement may reject single-field lithologic edges. Earlier work includes edge magnitudes, gradient cross-products, and upward-continuation persistence. The narrow proposed difference is a polarity-aware signed phase/curvature relationship, not another magnitude-only fusion. A related phase-pairing idea is already in the upstream backlog, but no completed compliant test for this precise transform was located. Moderate, conditional; low-to-medium compute. No numeric DTI gain is claimed. Uses existing competition layers; no new external source is required. The actual TIFF/cache is absent here. Not viable to test in this checkout; restore inputs and run the shared evaluator first.
2 Native-resolution LiDAR scarplet graph
USGS 3DEP 1 m elevation tiles, retaining native elevation and acquisition/quality masks before aggregation.		 Detect short asymmetric scarps at native resolution, link en-échelon segments by strike and bounded gaps, and measure whether chains persist across adjacent topographic panels before summarizing to the competition grid. Low-throw discontinuous scarplets can be averaged away in a 100 m cell. A chain spanning multiple drainages may be a structural trace even when each individual scarp is weak. Prior inspected systems use 100 m LiDAR-derived channels and pixel-level/short-window chains. The proposed object is a native-resolution segment graph, not simply a stronger 100 m scarp edge. Moderate, exposure-dependent; high storage/processing cost. Official source listed for review: USGS National Map Downloader / 3DEP. An upstream source-health log reports the landing page responded, but tile coverage, native resolution, license, and download bytes were not checked in this run. Do not call viable until a geospatial manifest and checksums are verified.
3 Unsmoothed microseismic plane geometry
Raw hypocenter locations, depth uncertainty, and available focal-mechanism nodal planes from USGS ComCat/FDSN; compare with the template's heavily smoothed seismicity layers.		 Fit uncertainty-weighted planes/lineaments to compact hypocenter clusters and project the supported strike to the map; require temporal and spatial coherence rather than using event density alone. Active buried structures may have microseismic expression without a clear surface scarp. The supplied smoothed count/distance layers can erase fault-scale geometry. Prior feature stacks use smoothed seismic layers; related raw-catalogue proposals were registered but not completed as a compliant holdout test. This would test point geometry and mechanism constraints, not another density raster. Potentially high but uncertain; high cost and potentially sparse coverage. Official source listed for review: USGS FDSN Event API (ComCat). An upstream source-health log reports the API landing page responded, but a region/date query, mechanism coverage, licensing, and uncertainty quality were not verified here. Not viable until the actual query and coverage are checked.

Required test sequence for rank 1

  1. Resolve the missing single-method lane paragraph. Freeze one method and its expected confounders before code changes.
  2. Restore official `training_features.tif`, `labels.tif`, `existing_faults.tif`, `sample_submission.tif`, and the template's cached stack. Verify hashes and band descriptions; do not infer band numbers from prior prose.
  3. Build each proposed signed/phase feature strictly from input layers. For every single feature, run the fold-local leakage canary on the shared whole-segment holdout; stop if oriented AUC exceeds 0.90 without a proven non-leakage explanation.
  4. Run the shared `evaluate_holdout.py` on the pre-registered candidate and an incumbent under the same folds, pooled metric, withheld positives, and 95% CI. Do not substitute a live-ledger projection for HOLDOUT-DTI.
  5. Before point placement, compute surface Spearman against the refreshed registry; after emission, compute directed 3-pixel dot overlap. Any threshold breach is a negative duplicate result, with no lattice exemption.
  6. Only if the holdout beats the current same-evaluator best and all other gates pass, write a new TIFF using the shared writer and validate the saved bytes. A separate selector—not this experiment—decides whether to use a live weekly slot.
