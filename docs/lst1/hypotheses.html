W1 — Ledger-supervised tomography (LST), executed

  • Layers (all in the repo mirror): 19 training bands, 12-band lidar-scarp stack (11 used), GeoDAWN radiometric (4) and extension (4) rasters, derived SGMC fault-distance, TIGER road distance, plus derived: gradient magnitude, Laplacian-of-Gaussian, local relief and gravity×magnetic cross-gradient at several scales, and distances to wellsprings/vents. 66 fields total (evidence/field_canary.json).
  • Physical signature: none by assumption. The method does not assert a fault signature; it measures which field bins carry hidden-truth density, using the only off-catalogue supervision that exists — the live scores of 112 distinct submitted rasters (each a "sensing pattern" of the hidden-truth field).
  • Why it can find uncatalogued faults: the official scoring masks catalogued pixels, so a model fitted to the catalogue learns where the known faults are; the ledger instead constrains where the new labels are.
  • Difference from prior work (stated narrowly): live-score inversion exists in GEMSDOE28 (knowledge/07_live_score_inversion.md, 20 rasters), GEMSDOE27 src/gems27/tomography.py (20 rasters, recorded as refuted) and GEMSDOE32 LLI (strata = catalogue distance × H19-5 distance, optional few factors). LST differs in: (i) 112 unique rasters instead of ≤ 60, (ii) 66 independent fields screened with nested leave-family-out CV so the reported error is not selection-biased, (iii) the fitted density is used to place dots with a Dinkelbach marginal-gain greedy, not only to rank existing files, (iv) an explicit cap on overlap with the H19-5 network because the ledger is confounded by that lineage. Verdict is by nested CV, not by assertion.
  • Failure modes recorded in advance: collinearity with the H19-5 lineage (all top ledger scores descend from it), so the on-network density is not identified; 112 measurements cannot resolve 5.2 M pixels; scores are owner-reported. If nested-CV MAE is not clearly below the nuisance-only baseline the verdict is NEGATIVE.

W2 — Ledger-residual gap fill (quota arm of W1)

Same machinery, but the allocation reserves a fixed fraction of dots for places the density model rates high and H19-5 has no dot within 3 px. Differs from GEMSDOE27 "H27-10 annulus" (a fixed geometric reallocation) by being density-driven. Cost is a parameter of the allocator.
