## Locked evaluation and stop rules

1. **Lane:** remain in the assigned single method lane. Do not fork `evaluate_holdout.py`, `submission_writer.py`, cached features, or shared template code. The pinned shared bootstrap is identified in `src/gems_project/template.py`; cache/runtime availability and upstream commit compatibility must be verified before an eligible run.
2. **Before any placement:** test surface rank-correlation against every registry raster; stop and record a duplicate if absolute correlation exceeds 0.90. Also stop if more than 70% of final dots fall within 3 px of any registered raster. The currently recorded dense witness already crosses the dot-overlap stop for any nonempty in-footprint raster; no placement/holdout is authorized now.
3. **Holdout, only after the stop is resolved:** hold out whole fault segments with a spatial buffer; derive catalogue features only from visible faults; pixel-exactly mask visible faults. Use the shared pooled DTI evaluator (α=0.2, β=0.8, 300 m triangular kernel) and matched folds/baselines. Test each feature alone for leakage; AUC >0.90 is leakage unless a documented, independent explanation resolves it. Do not substitute spatially adjacent pixels or a proxy score.
4. **Labels:** report every actual score as `HOLDOUT-DTI` with evaluator version, withheld-positive count, and 95% CI, or as `ORGANIZER-CONFIRMED` only when a verifiable submission receipt exists. A model estimate, projection, owner report, format check, or mirror comparison is never a score.
5. **Budget:** maximum three geological experiments or two hours, whichever occurs first. At preregistration: **0 experiments, 0 holdout runs, 0 candidate rasters, 0 selector actions, 0 weekly slots used**. Software tests and evidence verification are not geological experiments.
6. **Selector:** no real submission slot may be selected by this research lane. Any future promotion requires a separate selector step and explicit portal-cap check; it does not bypass duplication or format/evidence gates.
7. **Final artifact:** if and only if the lane becomes eligible, end with one machine-readable JSON run card containing the selected hypothesis/mechanism, named non-fault mimic, compliant HOLDOUT-DTI and CI, evaluator version/withheld positives, surface correlation and final-dot overlap, raster SHA-256, format-validator checks, submission name, note (≤140 characters), and `promote` or `negative` verdict. A negative card is a complete result.
