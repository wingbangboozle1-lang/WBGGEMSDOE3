## Irregularities and limitations

1. **Protocol ambiguity blocks every experiment:** Q1 (what exactly counts as a dot in a continuous raster) and Q2 (whether the binary lattice is a registry comparator) need a recorded decision before surface construction. Changing either rule unilaterally would violate the explicit stop condition.
2. **Source freshness is incomplete:** GitHub heads were checked 2026-10-31, but all nine changed relative to the older baseline. The source monitor did not fetch or compare the current raster contents. The official leaderboard/source text has not been refreshed since 2026-10-29.
3. **Competition data and shared cache are absent:** labels, full feature stack, fold assignments, and required shared holdout runtime are not present in this checkout. Hash-pinned mirrors are not authenticated organizer downloads.
4. **Submission format issue remains unresolved:** a previous upload error says predicted values were outside `[0,1]`, but the rejected file is not supplied, so its cause cannot be diagnosed. Current rules read in saved evidence specify null/NaN outside the bounds; some old artifacts use zeros outside. No portal acceptance test has been performed.
5. **Score provenance:** focus-site leaderboard values are owner-reported; the 0.4544/0.3330/0.3328 figures are a dated public leaderboard observation for other entries; none is a HOLDOUT-DTI or organizer receipt for this repository.
6. **AI disclosure/originality:** the saved official rules audit says generative-AI assistance must be disclosed in the narrative and work must meet the originality requirements. Any eventual competition submission requires the entrant to satisfy those rules.
7. **No authorized submission selection:** no current account quota/usage or submission receipt is accessible. A selector step remains separate from research validation.
