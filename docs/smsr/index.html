One caveat, reported transparently

A dense registry file still triggers the literal duplicate rule

The literal rule

One previously registered GitHub file (17GEMSDOE_E-proba-multiscale) is positive on 100% of the footprint (a smooth continuous surface, millions of unique values, not a sparse dot pattern). Any nonempty candidate therefore has directed 3-pixel overlap = 1.000 against it by construction — this is a mathematical property of a 100%-dense comparator, true for literally every possible submission, not a measurement of similarity to SMSR specifically.

The content-aware test

The same parallel-run paragraph also names rank correlation as a duplicate test. We ran it: Spearman ρ = 0.0942 across the shared footprint — far below the 0.90 cutoff. The two surfaces are essentially uncorrelated in content.

Why we still recommend this file

Against every meaningful comparator — all 9 requested GEMSDOE focus-site files, every prior lane in this repository, and the dense witness by rank correlation — SMSR passes both the ≤0.70 overlap and ≤0.90 |ρ| gates. It is flagged only by a test that is provably uninformative for a 100%-dense comparator. We report this to you rather than silently overriding the literal rule; the final submit decision is yours.

What the hypothesis is

Seismogeodetic Missing-Shear Ridge (SMSR)

Hypothesis. Walker Lane GPS/geodetic shear-strain rate (geod_2ndinv) exceeds what the mapped Quaternary catalogue can kinematically explain in places (Bormann, Hammond & Kreemer 2016, Geology 44:535, 'missing shear' across the central Walker Lane). Where that strain forms an anisotropic (elongated, not blob-like) ridge AND instrumental seismicity (deq_n100a15 / ieq_n100a15) corroborates it, the catalogue-masked gap is a candidate unmapped structure.

Mechanism. Structure-tensor coherence x log-gradient of geod_2ndinv (reusing gems57.strand_orientation.magnetic_geometry, originally built for TMI, applied here to a strain-rate scalar) distinguishes elongated tectonic strain ridges from isotropic non-tectonic blobs; deq_n100a15/ieq_n100a15 (never used in the shipped 9-plane gems57.geo.GEO_FEATURES block) add independent seismic corroboration. These 3 new planes are appended to the shared, pinned gems57 fault-zone-anatomy feature matrix and fit with the identical HistGradientBoostingClassifier recipe used by the template's shipped configuration.

Named non-fault mimic. Fluid-production/injection-induced subsidence or inflation at producing or developed geothermal fields (e.g., Dixie Valley, Brady's, Desert Peak, Steamboat Springs) and groundwater-pumping cones can generate local geodetic strain-rate anomalies unrelated to tectonic faulting. The anisotropy/elongation gate is a partial defense (production bowls are typically isotropic, not lineated), but no well/production-siting layer could be ingested in this sandbox (OpenEI/NV production GIS hosts are outside the outbound allowlist), so this mimic is reported, not fully deconfounded, and is flagged for the next session.

Full ranked hypothesis set and why this one was built first: knowledge/preregistration-2026-10-28-smsr.md.

Limitations of this clearance

  • No true organizer test label was available anywhere in this session; the HOLDOUT-DTI figures above are our own spatially-blocked hide-and-recover proxy, not an organizer-confirmed score. Label every number accordingly before acting on it.
  • 'd' and/or 'd_perp' (distance/cross-strike offset to nearest VISIBLE fault, inherited base features present in every gems57 anatomy configuration, identical in both shipped_g and smsr_g) exceed the 0.90 discriminative-AUC bar in both arms (0.9245 all-mode, 0.9353 detached-mode). This is a known, previously-documented characteristic of this exact hide-and-recover design (gems57.fitting.canary docstring: 'd is expected to be highly discriminative... but it must not be near-perfect'); 0.92-0.94 is flagged but not near-perfect (>0.99). It affects the ABSOLUTE 0.32 HOLDOUT-DTI level in both arms equally and therefore does not bias the SMSR-vs-shipped DIFFERENTIAL result, but the absolute number should be treated with this caveat. None of the 3 new SMSR planes individually exceeds 0.90.
  • The production/injection mimic for the geodetic-strain signal is named but not deconfounded with real well/production data (host not reachable from this sandbox).
  • Uniqueness was checked against 20 comparators (9 focus sites, prior lanes, and the dense witness), not the full set of 90+ GEMSDOE-family sites referenced in the project history; a wider scan is recommended before relying on this clearance for a second or third submission.
