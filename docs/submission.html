How to Submit — WBGGEMSDOE3 GEMS Prize

Step-by-step instructions for downloading, validating, and submitting the unique TIF file to the DOE GEMS competition.

1. Confirm You Have the Data

  1. Run bash scripts/download_competition_data.sh on an unrestricted machine.
  2. Place files in data/: training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv.
  3. Run python scripts/prepare_data.py to build feature stacks.

Note: Without this data, only the synthetic demonstration file is available. The synthetic file is format-valid but should not be submitted as a score improvement.

2. Generate the Submission TIF

  1. Run python scripts/generate_submission.py.
  2. The script writes to submissions/unique_submissions/gems-unique-h80-hydrothermal-conduit-20261026-000000Z-unique-sha.tif and a .zip.
  3. The script verifies float32, [0,1] range, no NaN, EPSG:32611, and writes a manifest.

3. Validate Before Submitting

  1. Run python scripts/validate_submission.py submissions/unique_submissions/gems-unique-h80-hydrothermal-conduit-20261026-000000Z-unique-sha.tif.
  2. Confirm output says PASS for format, range, and CRS.
  3. Read evidence/run_card.json — confirm VERDICT: PROMOTE (not NEGATIVE). Only submit if promoted.

5. Submit to Competition

  1. Visit Competition Submit Page.
  2. Click "Make new submission".
  3. Upload the .tif or .zip file.
  4. Fill the Note field with the submission name (≤140 chars): H80 LLI-unique hydrothermal-conduit 49231d 35%novel | LLI proj 0.230-0.255 <0.2778 | HR 0.084 [0.068,0.101] | UNIQUE not duplicate.
  5. Click Submit. Confirm there is no error message like "Predicted values must be in range [0, 1]".
Warning: The current file passes format checks (values in [0,1], float32, EPSG:32611, no NaN) but is marked NEGATIVE in the run card. Do not spend a weekly submission slot on it unless the run card changes to PROMOTE after real feature training and holdout validation.

6. Post-Submission Check

  1. Confirm receipt appears on the submission page.
  2. If a score appears, label it ORGANIZER-CONFIRMED in evidence/run_card.json.
  3. If no improvement, treat as negative result (deliverable per protocol).
