How to submit — only after clearance

DO NOT SUBMIT: no new competition TIFF is available. Format validity, scientific validation, novelty and weekly-slot authorization are separate gates. None should be replaced by a manual visual inspection.

  1. The project must finish the automated protocol: buffered segment holdout, fold-local features, canaries, paired improvement, complete-registry surface/dot novelty, and exact template validation.
  2. The independent selector must check the current weekly cap and approve a slot. We have not accessed the authenticated submission page or its current usage.
  3. Download only the TIFF whose SHA-256 matches the cleared run card. A future cleared release should put this link at the top of the executive page; there is deliberately no placeholder download now.
  4. Open the competition and its New submission form. Choose the single-band .tif (or ZIP containing only that TIFF). Use the generated unique name and note, limited to 140 characters by this project's policy.
  5. Retain the organizer receipt, timestamp, file hash and returned score. Only a matching submission-page receipt justifies ORGANIZER-CONFIRMED. A local holdout is not an organizer score.

Preventing “Predicted values must be in range [0, 1]”

Check every cell after writing, not just the footprint. NaN, infinity, negative nodata sentinels and values above one are disallowed by this project's all-finite policy. Set nodata to None for the all-finite release, verify the grid exactly against the sample, and read the result back. Do not silently clip a failed model to make it appear valid.

Local format-only command: .venv/bin/python scripts/audit.py raster candidate.tif data/sample_submission.tif. This command never grants submission clearance.
