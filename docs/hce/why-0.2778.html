PHD-LEVEL ANALYSIS / GEMSDOE32 H33 B2

Why did 0.2778 happen?

And can a scientifically different method beat it? The honest answer separates what the bytes prove, what the metric implies, and what only an organizer receipt can establish.

1 · What is actually measured

The value 0.2778 is an owner-reported claim for h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros. No submission-page receipt linking those bytes to that number was available; the public leaderboard is a time-stamped observation about other teams, not a receipt.

Independently re-reading the pinned TIFFs showed B2 is an exact support subset of GEMSDOE28's H27-4 base: 37,654 positive cells retained from 40,199. All 2,545 removed cells lie 1.41–2.00 px from the mapped fault mask; the closest kept cell is 2.24 px away. This is catalogue-proximity pruning — a measured property of the file, not a proven cause of the score.

2 · The decision-theoretic mechanism

The official metric is a distance-weighted Tversky index with α=0.2 (false positives cheap), β=0.8 (false negatives expensive), and a triangular kernel k(d)=max(1−d/3, 0) at 100 m/px. Written in the official notation, TPw=Σg∈Gmaxx p(x)k(d(x,g)). Three consequences follow:

  • Max-credit, not sum-credit. Each ground-truth pixel takes its single best prediction within 300 m. A 2–3 px dotted lattice along a line yields almost the same credit as a solid line at a fraction of the false-positive mass. The B2/D2.8 family is exactly such a lattice on the H19-5 ridge network.
  • False positives are discounted 5:1. DTI = TP/(TP+0.2FP+0.8FN). With ~37.6 k dots and an estimated ~12.7 k hidden truth pixels, the denominator is dominated by 0.8·FN, so broad coverage of plausible traces beats a timid, high-precision set — as long as the extra dots are not mostly far from truth.
  • Catalogue exclusion matters. The hidden test set consists of expert-labeled faults not in the public USGS/INGENIOUS catalogue. Dots on mapped traces cannot become true positives and are pure 0.2-cost false positives. Removing the 2,545 near-catalogue dots is the rational move.

Formally, for a fixed truth set G with coverage c=TP/|G| and N emitted dots, DTI ≈ c|G| / (0.2c|G| + 0.8|G| + 0.2N). Solving for the observed 0.2778 with N=37,654 and |G|≈12,691 requires c≈0.41 — i.e. roughly 41% kernel credit on hidden faults. That is far above the ~9% credit these files obtain on the independent off-catalogue SGMC trace population measured here, which tells us the hidden expert labels are much more aligned with the H19-5 lineament network than SGMC traces are (or that the |G| estimate is wrong). Both explanations are unverified; only the hidden labels and a receipt can decide.

3 · Can we do better?

Three distinct evidence streams disagree, and all three are reported:

Fold-legal holdout — YES

Our E4 physical-susceptibility lattice scores HOLDOUT-DTI 0.1292 (95% CI 0.1160–0.1426, 22,232 withheld positives, GEMSDOE32-HIDE-RECOVER-v3.0) against the replayed champion proxy 0.0992; paired Δ +0.0300, 95% CI +0.0177–+0.0417. A dot-count-matched random lattice control scores 0.0734, so the ranking adds signal. Caveat: the champion proxy is leakage-contaminated (H19-5 was built from the full catalogue).

Released-file static holdout — MIXED

After the mandatory registry-novel repair, the actual downloaded bytes score 0.0931 (95% CI 0.0824–0.1037) as a static read-back. It is a diagnostic, not fold-local out-of-fold scoring.

Owner-reported ledger projection — NO

A leave-one-out ridge model on 117 owner-reported sibling scores (LOO MAE 0.0287) projects 0.082 (p10–p90 0.024–0.140) for our pattern. The top of that ledger is one tightly related dot family, so the projection is severely out-of-distribution and probably pessimistic — but it is not evidence that we beat 0.2778.

Conclusion. We can produce a genuinely new, format-valid, holdout-winning submission. We cannot honestly claim a score above 0.2778 (or above the current public leaderboard) without an organizer submission-page receipt tied to our uploaded SHA-256. Any statement to the contrary would be a projection dressed up as a score.
