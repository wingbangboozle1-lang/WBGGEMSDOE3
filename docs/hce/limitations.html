Scientific limitations

  • Holdout ≠ hidden test. Hide-and-recover withholds catalogue faults, while the competition's private set is expert-labeled new faults. The released file's static read-back HOLDOUT-DTI is 0.0931 (95% CI 0.0824–0.1037); the fold-local method result is 0.1292. Neither is a leaderboard score.
  • Champion proxy is leakage-contaminated. The H19-5/D2.8 network was built from the full catalogue, so the 0.0992 incumbent contains hidden segments. The paired win is real but the comparison is conservative in an unusual way.
  • Projection is out of family. LOO MAE 0.0287 on 117 owner-reported scores, but the top of that ledger is one related dot family; a novel pattern is extrapolated. Use the p10–p90 band 0.024–0.140, not the point estimate.
  • Uniqueness has a price. The repair moved ≥38% of dots into registry-novel cells and reduced static holdout DTI. Max sparse overlap is now 0.524; the unconstrained pattern was 0.837 (a duplicate).
  • Mirror provenance & band semantics. SHA-256 pins prove mirror consistency, not official origin. Some 19-band names (notably tc) remain ambiguous; do not assert physical meaning from the mirror description alone.
  • One ledger raster unavailable. One of 118 pinned live-scored rasters returned HTTP 404 from GitHub; 117 were verified. Flag for the owner to re-pin.
  • Shared tool defects upstream. The shared uniqueness tool tests one-sided ρ>0.90 while the protocol needs |ρ|; the shared metric docstring's marginal-credit bound is wrong. Neither was forked; both need maintainer fixes.
  • External data not obtained. Raw 1 m 3DEP tiles, ASF InSAR and GDR thermal archives were not downloaded; hypotheses 2–4 remain untested. All are free/official but need byte-level verification and licence review.
  • Compute/data placement. bash scripts/download_competition_data.sh now performs placement autonomously via pinned public mirrors; GPU is not required for this lane, but the 419 MB feature stack must be re-fetched on a fresh clone.
