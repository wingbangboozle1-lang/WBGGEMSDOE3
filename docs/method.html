Method and safeguards

Measured on withheld ground, audited against every raster we hold.

1 · Data

Organizer telemetry (19 bands), the published catalogue labels.tif (1 = mapped fault, 0 = mapped absence, NaN = outside the sample footprint), and the 5,167,373-cell footprint. Labels SHA-256 7ba308ccdc4418b31a178f4f1ef21aaa6e152e4028f2f6f64b01f7eb25ae4093.

2 · Geometry

σ = 24 px Gaussian density of the visible catalogue → restrict to 3 ≤ dvis < 12 px → greedy thinning at 4 px minimum separation, highest density first. The emission domain is the whole footprint; dots are never placed on a known fault or outside the footprint.

3 · Holdout

20 % of 8-connected catalogue segments withheld per fold, stratified by quadrant, dilated 2 px. The prior for each fold is rebuilt from that fold's visible catalogue only. 3 folds, 36,949 withheld pixels.

4 · Metric

gemsw.metric.dti_binary alpha=0.2 beta=0.8 R=3px (2026-10-31 build) — the competition DTI with α = 0.2, β = 0.8, R = 3 px on the binary map, visible catalogue masked as known. Implemented once in src/gemsw/metric.py and reused by every experiment.

5 · Uncertainty

300-rep block bootstrap, 256-px blocks, on the per-truth and per-dot kernel weights. Paired deltas reuse the same block draws for candidate and baseline so the block-to-block variance cancels.

6 · Leakage canary

Every channel that reaches the model is scored directly against withheld pixels. Max AUC 0.754 ≤ 0.90. The positive control (distance to the withheld truth) scores 1.000: the canary provably fires when leakage exists.

7 · Uniqueness

Byte SHA-256, identical support, Jaccard, bidirectional 3-px dot overlap and Spearman on 600 k smoothed samples against 28 registry rasters. Thresholds: ≤70 % overlap, |ρ| ≤ 0.90, no byte duplicate.

8 · Saved bytes

The validator re-opens the written file — not the in-memory array — and checks band count, dtype, CRS, shape, transform, range, NaN/Inf, and that positives lie inside the footprint and off known faults. All checks pass.

STATED SCOPE LIMIT

The uniqueness rule was applied to all 28 registry rasters available in this sandbox (the nine focus sites, the repository download archive and this lane's own files). The registry index lists 522 entries / 296 unique dot masks, so the remaining entries could not be audited here. The candidate is a deterministic function of the organizer's published labels and fixed hyperparameters -- no registry raster enters its construction -- so an unaudited raster can only overlap it by coincidence.
