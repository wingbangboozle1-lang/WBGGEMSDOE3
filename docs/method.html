Parallel-run and leakage protocol

  1. Remain in one explicitly assigned method lane and reuse the shared cached feature stack, evaluate_holdout.py, and submission_writer.py. Never fork shared tools. The current lane is unassigned.
  2. Before placement, check surface rank correlation against every registry raster; stop if |Spearman| >0.90. After placement, stop and log a duplicate if more than 70% of final dots are within 3 px of any registry raster.
  3. Hold out whole fault segments with a buffer; derive catalogue features only from visible faults; pixel-exactly mask visible faults; pool DTI using α=0.2, β=0.8, and a 300 m triangular kernel.
  4. Test every feature alone for leakage. AUC >0.90 is leakage until an independent explanation is established.
  5. Every actual score needs evaluator version, withheld-positive count, and 95% CI. Public leaderboard values and model projections are separate; a projection is never a score.
  6. Stop after three geological experiments or two hours. No real slot selection in this lane; a separate selector checks the live cap.
